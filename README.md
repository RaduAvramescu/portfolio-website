## Color themes

The site follows the device theme and remembers changes made with the navbar
toggle. Theme colors use `light-dark()` in `src/styles/globals.css`.

## Validation

Run these checks before opening a pull request:

```sh
pnpm run lint
pnpm run format:check
pnpm run check
pnpm run build
```

`pnpm run check` runs Astro diagnostics, including TypeScript checks inside
`.astro` components.
